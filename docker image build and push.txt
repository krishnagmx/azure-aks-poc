If you don't want to change your subscription for now, you can bypass ACR Tasks, build the image locally with Docker, and then push it to ACR:

bash
# 1. Log in to ACR
az acr login --name akspocacruypykm

# 2. Build the image locally (tag format must include the ACR address)
docker build -t akspocacruypykm.azurecr.io/backend:v1 -f src/backend/Dockerfile src/backend

# 3. Push to ACR
docker push akspocacruypykm.azurecr.io/backend:v1

# 4. Verify
az acr repository list --name akspocacruypykm --output table
Note: This method requires Docker Desktop (or another Docker runtime) to be installed and running locally.
